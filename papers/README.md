# AncientScriptLab

# Research Papers

This directory contains internal scientific papers and research notes produced during the development of AncientScriptLab.

These documents record:

- research questions;
- experimental designs;
- validation protocols;
- scientific observations;
- architectural decisions related to research;
- conclusions drawn from computational experiments.

The purpose of these papers is to preserve scientific knowledge independently of source code.

Every important scientific decision should be documented here.

Code explains how the system works.

Research papers explain why scientific decisions were made.
