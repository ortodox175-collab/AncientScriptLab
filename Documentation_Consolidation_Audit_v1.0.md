# Цель документа

Настоящий документ фиксирует результаты ревизии ключевой документации AncientScriptLab.

Каждый вывод имеет один из трёх статусов:

- **Подтверждено документами** — вывод непосредственно следует из существующей документации проекта.
- **Аналитический вывод** — вывод получен в результате сопоставления нескольких документов.
- **Рекомендация** — предложение по дальнейшему развитию проекта.

Документ является основой для обновления ROADMAP_V3.md и дальнейшей разработки проекта.

---

# Раздел I. Подтверждено документами

## 1. Главная цель проекта

**Статус:** Подтверждено документами

AncientScriptLab предназначен для объективного структурного исследования письменностей без предварительной интерпретации их значения.

Подтверждается документами:

- PROJECT_PHILOSOPHY.md
- ASL-000-Research-Methodology.md
- SCIENTIFIC_WORKFLOW.md

---

## 2. Научный принцип проекта

**Статус:** Подтверждено документами

Основной принцип:

**Measure first. Compare second. Hypothesize last.**

(Сначала измерение. Затем сравнение. Затем гипотезы.)

---

## 3. Роль египетского корпуса

**Статус:** Подтверждено документами

Египетский корпус используется как референсный корпус для проверки методов лаборатории.

Подтверждается статистическими и валидационными отчётами.

---

## 4. Значение канонического реестра

**Статус:** Подтверждено документами

Канонический реестр является фундаментом идентичности знаков.

Подтверждается блоком reports/metrology.

---

## 5. Значение валидации

**Статус:** Подтверждено документами

Валидация направлена на проверку воспроизводимости научного конвейера обработки данных.

Подтверждается:

- M10_PIPELINE_VALIDATION_REPORT.md
- M10_FINAL_VALIDATION_CERTIFICATE.md

## 2. Иерархическая идентичность знака

**Статус:** Аналитический вывод

Знак имеет несколько уровней идентичности:

- категория;
- подкатегория;
- ориентация и конфигурация;
- конкретный знак;
- графический вариант.

Этот вывод основан на сопоставлении:

- системы Гардинера;
- метрологических документов;
- статистического анализа корпуса.

---

## 3. Архетипическая система

**Статус:** Аналитический вывод

Архетипы представляют собой структурные классы знаков, а не интерпретацию их значения.

Основание:

- archetype_* reports;
- structural_primitive_report_v1.md.

---

## 4. Основной риск документации

**Статус:** Аналитический вывод

Методология проекта распределена между несколькими документами и не собрана в единую нормативную систему.

# Раздел III. Выявленные противоречия

## 1. Инвариантность к повороту

**Статус:** Аналитический вывод

METROLOGY.md содержит требования инвариантности к повороту.

Эпиграфическая модель требует сохранения ориентации как потенциально значимого признака.

Требуется согласование.

---

## 2. Отсутствие иерархической валидации

**Статус:** Аналитический вывод

Текущая система валидации проверяет воспроизводимость, но не проверяет корректность иерархической идентичности знаков.
