# Scientific Development Principles

AncientScriptLab performs **objective computational analysis of writing systems**.

The platform does **not**:

* interpret symbols;
* perform automatic decipherment;
* replace scientific judgment.

Instead, it objectively measures and preserves mathematically verifiable properties of written symbols.

Scientific interpretation always remains the responsibility of the researcher.
