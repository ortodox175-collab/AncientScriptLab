# Purpose

This document provides the recommended reading order for the
AncientScriptLab documentation.

The documentation is organized from scientific philosophy to
software implementation.

Reading the documents in this order provides a complete understanding
of the project.

---

# Guiding Principle

Understanding the philosophy of the project is more important than
understanding individual source files.

Architecture follows philosophy.

Implementation follows architecture.

Scientific results follow implementation.

---

# Scientific Mission

AncientScriptLab is an objective scientific measurement platform.

It does not replace researchers.

It provides reproducible computational evidence that enables
scientific investigation of ancient writing systems.
